Security

Effective 2026-07-28

Reporting a vulnerability

Email security@findanything.dev with steps to reproduce. We aim to acknowledge within 72 hours. Please practice coordinated disclosure: give us 90 days (or agree on a timeline) before publishing. There is no bug bounty — this is a pre-revenue independent project — but we will credit reporters in the repository changelog if they wish.

Scope

  • This website — a static site with no server-side code, no authentication, no cookies, no user data storage, and no upload endpoints. Its attack surface is intentionally minimal, and it ships a restrictive Content-Security-Policy and security headers.
  • The AIR software — the analysis engine, evidence format, and standalone verifier. Reports about the cryptographic record format (Merkle construction, signature handling, verifier bypasses, tamper-detection gaps) are especially welcome: the record is designed to be challenged.

What the record's cryptography claims — and doesn't

AIR's record format shows integrity: that a record (both report.json and report.html) has not changed since signing and that source files match their committed digests. The verifier checks the signer against a key fingerprint the operator publishes separately; that shows which key signed, not who controls it (there is no identity PKI). It checks an RFC 3161 token's imprint and signature, and validates the timestamp authority's certificate chain only when given a trusted CA (--tsa-ca). It makes no legal claim. If you can break the integrity property, we want to know urgently.

Out of scope

Volume-based attacks on the static host, reports about third-party services (Cloudflare), and social engineering of the developer.
